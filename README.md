## 📖 About

Myanmar Backend Engineering Library is an open-source project dedicated to providing high-quality backend engineering resources in the Myanmar language.

Our goal is not only to teach Laravel, but also to help developers become professional backend engineers through real-world projects, software engineering principles, and production-ready practices.

---

## 🎯 Vision

To make world-class backend engineering knowledge freely accessible for every Myanmar developer.
