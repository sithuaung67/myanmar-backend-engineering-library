# 📖 About

Myanmar Backend Engineering Library is an open-source educational project dedicated to providing high-quality backend engineering resources in the Myanmar language.

This project goes beyond teaching a framework. It focuses on software engineering principles, backend architecture, real-world Laravel development, and production-ready practices.

Our goal is to help developers build reliable systems, think like engineers, and contribute back to the community.

---

# 🎯 Vision

To make world-class backend engineering knowledge freely accessible to every Myanmar developer.
