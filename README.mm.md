# 📖 အကြောင်းအရာ

Myanmar Backend Engineering Library သည် မြန်မာ Developer များအတွက် Backend Engineering ဆိုင်ရာ အသိပညာများကို အရည်အသွေးမြင့်စွာ စုစည်းပေးသည့် Open Source ပညာရေး Project တစ်ခုဖြစ်သည်။

ဤ Project သည် Laravel Framework ကို သင်ကြားပေးရုံသာမက Software Engineering Principles၊ Backend Architecture၊ Production-ready Development နှင့် Real-world Project အတွေ့အကြုံများကိုပါ မျှဝေရန် ရည်ရွယ်ပါသည်။

ကျွန်ုပ်တို့၏ ရည်မှန်းချက်မှာ Developer များကို Code ရေးတတ်သူအဖြစ်သာမက Backend Engineer တစ်ယောက်လို စဉ်းစားတတ်သူအဖြစ် ဖွံ့ဖြိုးလာစေရန် ဖြစ်သည်။
