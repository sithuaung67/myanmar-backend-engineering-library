# 🔒 Security Policy

Thank you for helping keep this project secure.

## Reporting a Security Issue

If you discover a security issue in any source code or example, please do not create a public issue immediately.

Instead, contact the project maintainer privately with:

- Description
- Steps to reproduce
- Impact
- Suggested fix (optional)

We will review and respond as soon as possible.

---

## Scope

This policy applies to:

- Sample code
- Example APIs
- Documentation examples

Thank you for helping improve the project.
