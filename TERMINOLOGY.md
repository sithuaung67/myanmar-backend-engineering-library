# 📚 Engineering Terminology Guide

This document defines the standard technical terms used throughout the Myanmar Backend Engineering Library.

To maintain consistency, contributors should follow these terms whenever possible.

---

# 🎯 Purpose

Our goal is not to translate every technical word into Myanmar.

Instead, we use terminology that is:

- Familiar to developers
- Consistent across all books
- Easy to search online
- Compatible with official documentation

---

# 🌐 Language Policy

Documentation

→ Myanmar

Code

→ English

Technical Terms

→ Mostly English

Explanation

→ Myanmar

---

# ❤️ Philosophy

Use Myanmar to explain ideas.

Use English for technical precision.

This balance makes the documentation easier to understand while remaining compatible with the global software engineering ecosystem.
