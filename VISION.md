# Vision

## Our Vision

To build world-class backend engineering resources written in the Myanmar language.

We believe knowledge becomes more valuable when it is shared.

Our long-term goal is to help every Myanmar developer learn backend engineering through practical examples, real-world projects, and engineering best practices.

This project focuses on:

- Backend Engineering
- Software Architecture
- System Design
- Clean Code
- Performance
- Security
- Open Source

We are building this project for the next generation of Myanmar developers.

Knowledge belongs to everyone.
